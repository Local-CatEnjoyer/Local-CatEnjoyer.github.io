01 · About

Hi, I'm LCE.

LCE stands for Local Cat Enjoyer — the name I build and post under. Off the handle, I'm a student working across sound design, game audio, music production, programming and game development.

Most of what's here started as an experiment: a boss theme for a game that didn't exist yet, an ambience patch built just to see what REAPER's stock plugins could do, a script written to fix a problem I made for myself. This site collects that work as it grows.
